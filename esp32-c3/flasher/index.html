STOMPBOX Flasher

Installs the STOMPBOX Controller firmware on an ESP32-C3 board, straight from the browser.

  1. Use Chrome or Edge on a computer (not a phone).
  2. Connect the ESP32-C3 with a USB-C data cable.
  3. Click Install, pick the board's port (often “USB JTAG/serial debug unit”) and confirm.
  4. After about a minute, join the Wi-Fi STOMPBOX-CTRL (password stompbox123) – the settings page opens.
This browser can't flash boards. Use Chrome or Edge on a computer. Flashing needs a secure page (https).

If the board isn't found: hold its BOOT button while plugging in the cable, then click Install again. A first install erases the board. Later updates can be done over Wi-Fi from the settings page (/update), keeping all settings.
