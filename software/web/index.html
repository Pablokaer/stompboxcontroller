Saved networks

The Pi has one Wi-Fi radio, so when it joins a network the STOMPBOX-CTRL hotspot restarts on that network's channel. If you're on the hotspot, your phone drops for about 30 seconds: rejoin STOMPBOX-CTRL and the result shows here. From then on the page is also reachable on that network at the address shown above.

Footswitch profile

Each profile keeps its own settings. The active profile is the one the Pi listens to.

Buttons

Combos (press together)

Press the selected buttons within the combo window to fire the combo instead of their single actions.

Timing

Buttons with a hold action fire their press action on release, so a hold can be told apart from a tap.

Test pad

Works like the real footswitches (tap, hold, or press several at once) using the saved settings. The green dot under a pad lights while that real footswitch is pressed – handy for checking the wiring.
